# W4 离线模型对比与准入报告（R2）

## 1. 实验目的与结论

本实验针对五类农产品批发价格，比较 ARIMA 与 Prophet 的离线预测误差，按品类择优，并以测试集 MAPE ≤ **30%** 作为预测展示门槛。30% 是本系统的工程展示规则，不是统计置信水平，也不表示未来误差一定低于 30%。本系统用于行政性监测与预警，**预测结果仅供参考，不构成任何买卖建议**。

本次固定快照中，黄瓜和鸡蛋选用 Prophet，大白菜、猪肉选用 ARIMA。西红柿虽然由 ARIMA 胜出，其 MAPE 仍为 39.356%，因此不发布预测。共发布四品类 × 7 天 = **28 条**。

## 2. 数据与评估口径

- 实验日期：2026-09-27，Asia/Shanghai。仅查询已经入库的 `price_daily`，实验与预计算不调用采集器。
- 映射：大白菜→大白菜，黄瓜→黄瓜，西红柿→番茄，猪肉→白条猪，鸡蛋→散鸡蛋；仅保留 `unit_info='斤'` 的有效价格，按日期求明细算术均值。
- 时间窗口：**2024-09-28 至 2026-09-27**，730 个日历日。窗口锚定快照截止日，避免复跑时随系统日期移动；未来预测日期为 2026-09-28 至 2026-10-04。
- 固定时间切分：前 80%（584 天，至 2026-05-04）训练，后 20%（146 天，2026-05-05 起）测试，不打乱顺序。
- 缺测日线性插值。先划分日历段，再分别插值；训练段不得读取测试值，边缘用本段端点补齐。测试段可用最后训练点作起点。全量重估使用全窗口插值序列。
- 观测不足 120 天、非正或非有限价格拒绝进入模型；MAPE 非有限或未来价格非正的候选不参加择优。本次五品类均满足输入条件。
- 大白菜、黄瓜、西红柿各 715 个有效观测日、15 个缺测日；猪肉、鸡蛋各 713 个观测日、17 个缺测日。
- MAPE 定义：`100 × mean(abs((实际值 - 预测值) / 实际值))`，单位为百分数。评估为训练段末尾一次性预测整个 146 天测试段，不进行测试段滚动重训。

固定日均快照：[snapshot.csv](experiments/r2/snapshot.csv)；完整数值、预测向量、AIC、版本与耗时：[comparison.json](experiments/r2/comparison.json)。UTF-8/LF 规范化快照 SHA-256：

## 3. 模型设置与择优规则

**ARIMA**：延用 W1 五组候选 `(1,1,1)、(2,1,1)、(1,1,2)、(2,1,2)、(3,1,2)`，仅在训练段按最小 AIC 选阶；随后计算留出测试集 MAPE，再用全窗口重估该阶数，预测未来 7 天。五品类所选训练 AIC 分别为 -1687.928、-699.170、-1313.010、-414.921、-1604.850。

**Prophet**：固定加法季节模型，年周期 Fourier 阶数 5、周周期阶数 3、不启用日内周期；`changepoint_prior_scale=0.05`、`seasonality_prior_scale=10`、`uncertainty_samples=0`、拟合 seed=42。未加入节假日或其他外生特征，未利用本次留出集反复调参。由于训练段不足两年，显式启用低阶年周期作为季节模型对照；Prophet 对周期可识别性产生提示，该限制在第 5 节讨论。

**跨模型择优**：比较同一测试段的未四舍五入 MAPE，较小者胜出；完全相同时优先 ARIMA。不将 Prophet 与 ARIMA 的 AIC 混合排序。择优之后，再以未四舍五入的 MAPE 判断 `≤30%` 是否准入。

环境：Windows、Python 3.12.10、Prophet 1.4.0、statsmodels 0.15.0、pandas 3.0.6、NumPy 2.5.3。Prophet 使用 PyPI 官方 Windows wheel 安装成功，未使用 SARIMAX 备选。安装与配置参考 [Prophet 官方安装文档](https://facebook.github.io/prophet/docs/installation.html) 和 [季节项文档](https://facebook.github.io/prophet/docs/seasonality%2C_holiday_effects%2C_and_regressors.html)。

## 5. 简要分析与论文使用边界

1. **模型效果依品类而异。** 黄瓜的 Prophet MAPE 较 ARIMA 下降约 14.865 个百分点，并从超过门槛转为可展示；鸡蛋下降约 1.872 个百分点。猪肉上 ARIMA 的误差明显更低，说明不能对五品类统一替换为 Prophet。
2. **择优不能代替质量门禁。** 西红柿两模型都超过门槛，选择较优 ARIMA 后仍应停止发布。数据库及页面已执行此规则，不用高误差曲线填补展示区域。
3. **年周期估计存在局限。** 584 天训练段包含不足两个完整年周期，趋势与年周期可能难以稳定区分；大白菜的 Prophet 误差达到 179.525%。低价格基数会放大百分比误差，但本实验不足以证明某一因素是误差的唯一原因。这里保留失败对照结果，不为改善报告数值而改动测试区间或反复调参。
4. **这是一轮离线模型选择结果。** 同一留出段被用于择优，获选误差不是独立的最终泛化评估；缺测测试日的插值值也不等同于实测值。146 天一次性外推误差不能直接当作未来 7 天滚动预测误差。后续可增加滚动起点验证、多个时间窗口与独立保留段验证。
5. 用户给出的旧版 MAPE 属此前快照/窗口结果。本轮快照已更新到 2026-09-27，窗口严格取 730 日并隔离切分边界插值，因此应在本轮 ARIMA/Prophet 同口径结果之间作比较，不能将新旧误差差异全部归因于 Prophet。

## 6. 发布链路与复跑

预计算与实验共用模型函数。全部品类训练完成后，在一个事务内发布：准入品类保留本次模型和未来 7 天窗口，撤下旧模型或旧窗口，使用 `executemany` 与既有 `uk_pred` upsert；拒绝品类跳过写入并删除其旧派生预测。事务失败整体回滚，训练失败不发布新批次。保留的实验快照与 JSON 用于离线归档，`predict_result` 作为当前展示结果，不承担预测历史档案功能。

直接运行预计算和调度入口都会写一条 `collect_log`，记录阈值、模型、MAPE、跳过原因与条数；调度包装器避免重复记日志。所有新增 SQL 数据值均通过参数绑定。无 DDL 或 Java/后端接口变更。

后端空预测仍返回既有业务 code=404；前端仅对预测接口将其转换为正常空状态，展示“波动过大，暂不提供预测（仅供参考）”。其他网络/接口错误显示“加载失败”，不冒充准入拒绝。由于本轮保持接口不变，空数据契约无法区分未预计算与门禁拒绝，部署时应先成功完成预计算再开放展示。图例使用实际模型名，支持 ARIMA 与 Prophet。

项目根目录执行：

```powershell
python -m pip install -r python/requirements.txt
# 从当前数据库生成新的对比快照（不爬取）
python python/ml/compare_models.py --output-dir python/data/model-comparison
# 复跑本报告固定快照
python python/ml/compare_models.py --snapshot docs/experiments/r2/snapshot.csv --output-dir python/data/r2-replay
# 发布默认30%准入结果，自动记录 collect_log
python python/ml/precompute.py --snapshot docs/experiments/r2/snapshot.csv
# 验收用：撤下全部预测，验证后必须恢复默认门槛
python python/ml/precompute.py --snapshot docs/experiments/r2/snapshot.csv --threshold 0
python python/ml/precompute.py --snapshot docs/experiments/r2/snapshot.csv
python python/tests/test_smoke.py
```

数据库凭据继续来自本地环境变量/已忽略的 `python/.env`。日常调度不传 `--snapshot`，读取当日已入库快照；升级代码后须重启已有常驻调度进程，使其加载新逻辑。
